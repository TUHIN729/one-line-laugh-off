One-Line Laugh-Off: a program that writes exactly one original funny line to `/output/entry.txt` — a single joke that lands on a cold read, with no setup notes and no explanation.

## Run

```sh
node main.ts
```

Requires Node 22 or later. The program is deterministic: it writes the line to `/output/entry.txt` with no network access and no model call.

## Entry

> I hired a professional mourner for my funeral — she cried so well my ex asked for her number.
